# Repository Architecture

## 1. Project Overview

This project audits the accessibility and performance
of the public-facing Flipkart website.

Website: https://www.flipkart.com/

## 2. Project Structure

- client/: Frontend placeholder
- server/: Backend placeholder
- docs/: Documentation and audit reports
- tests/: Testing checklist
- screenshots/: Audit evidence

## 3. Tools Used

- Google PageSpeed Insights
- Google Lighthouse
- GitHub
- Chrome browser

## 4. Data Flow

1. Open the Flipkart website.
2. Run a mobile Lighthouse audit.
3. Record the scores and warnings.
4. Document five audit findings.
5. Recommend improvements.
6. Upload the report and evidence to GitHub.

## 5. First Feature

The first feature is an accessibility audit report
containing findings, evidence, priorities,
and recommended improvements.

## 6. Limitations

This is an independent student audit.
The client and server folders are placeholders.
Further manual testing is required.
