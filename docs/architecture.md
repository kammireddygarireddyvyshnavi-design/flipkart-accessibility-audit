# Repository Architecture

## 1. Project Overview

This project evaluates the accessibility and performance of the public-facing Flipkart website.

**Website:** https://www.flipkart.com/

**Project Name:** Flipkart Accessibility and Performance Audit

**Purpose:** To identify potential accessibility and performance issues, document evidence, and recommend improvements.

The project is an independent student audit. It does not modify or belong to Flipkart.

## 2. Project Objectives

- Evaluate website performance using Google Lighthouse.
- Review automated accessibility findings.
- Perform manual accessibility checks.
- Document five accessibility or architecture findings.
- Record evidence and remediation priorities.
- Maintain a clear and organized GitHub repository.
- Recommend improvements based on observed results.
