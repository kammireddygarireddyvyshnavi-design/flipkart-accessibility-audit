# Flipkart Accessibility Audit Report

## 1. Project Overview

Website: https://www.flipkart.com/

Purpose: To evaluate website accessibility and
document issues that may affect users.

## 2. Audit Methods

- Google Lighthouse accessibility audit
- Keyboard-only navigation
- Manual inspection of visible interface elements

## 3. Accessibility Findings

Status: Pending verification
