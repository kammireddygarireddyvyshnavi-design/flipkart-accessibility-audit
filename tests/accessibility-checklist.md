# Accessibility Testing Checklist

## Keyboard Navigation

- [ ] Navigate using Tab.
- [ ] Navigate backwards using Shift + Tab.
- [ ] Activate controls using Enter or Space.
- [ ] Check visible keyboard focus.

## Images

- [ ] Inspect alternative text for meaningful images.

## Forms

- [ ] Check accessible names for form controls.

## Color Contrast

- [ ] Check text and background contrast.

## Headings

- [ ] Inspect heading hierarchy.

## Results

Record actual findings and evidence after testing.
